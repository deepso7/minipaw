---
title: Introduction
description: minipaw pipes stdin/stdout between two machines, peer to peer. Like netcat, but it gets through NATs, needs no accounts, and every byte is end-to-end encrypted.
---

One side listens and prints a ticket; the other pastes it. Whatever goes into
one side comes out of the other.

```console
$ minipaw                                  # machine A
# 🐾 listening; connect with:
minipaw mpAQDEiiVb-s5zPPFvR0SjX0lVJgAkCAESINgMwzfDtX-D_vKZ0slyfVb4K-lw-ijkyHNLfPt1UkM2

$ echo hello | minipaw mpAQDEiiVb-s5zPPF…  # machine B
```

minipaw is built on [minip2p](https://github.com/deepso7/minip2p), a small
libp2p implementation in Rust. Start with [Installation](/docs/installation).
